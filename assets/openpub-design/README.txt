OpenPub — pack de design

1. Contenu : index.html, styles.css, assets/ (logos PNG, openpub.ico, aperçu).
2. Déployez le contenu du dossier sur votre Azure Static Web Apps.
3. Gardez OpenPub-1.3.0.msi à la racine du site (le bouton pointe vers /OpenPub-1.3.0.msi).
4. Pour l’installateur Windows, utilisez assets/openpub.ico comme icône de l’exécutable / application.
5. IMPORTANT : apercu-openpub-concept.webp est un visuel de maquette généré, pas une capture de l’application réelle. Vous pouvez le remplacer par une vraie capture, en gardant le même nom de fichier.
6. Adaptez la version, la taille de l’installeur et l’URL quand vous publiez une nouvelle version.
7. Les polices DM Sans et Plus Jakarta Sans sont chargées via Google Fonts. Une police système de remplacement est prévue.
